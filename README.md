# Yashwant Jaiswal – Portfolio

Modern, interactive and animated personal portfolio of **Yashwant Jaiswal**, Full Stack Web Developer and BCA student at Integral University, Lucknow.

🔗 **Live:** https://yashwantj730-code.github.io/yashwant-portfolio/

## Features
- Dark neon theme, typing animation, scroll-reveal, animated skills
- Projects pulled live from GitHub
- Education timeline and CodeWithHarry Data Analytics certificate
- Contact form (works with the Node.js backend in `/backend`, falls back to email)

## Tech
HTML, CSS, JavaScript (frontend) • Node.js, Express, MongoDB/Nodemailer (backend)

## Backend
See [`backend/README.md`](backend/README.md) to run it locally or deploy on Render, then set `API_URL` in `index.html`.
